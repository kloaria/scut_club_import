# 🎓 SCUT 社团成员批量录入助手

> 告别重复填写，让社团成员录入更简单！

一个基于 **Python + Playwright** 开发的浏览器自动化工具，用于辅助华南理工大学社团管理人员批量录入社团成员信息。

只需提前准备成员名单，登录学校办事大厅，即可通过脚本自动填写成员信息，减少重复操作，提高工作效率。

## ✨ 功能特色

- 🚀 **批量自动录入**：自动读取成员名单，依次填写学号、姓名、联系电话和政治面貌。
- 🧠 **智能识别页面**：支持 iframe 页面结构及动态表单组件。
- 🎯 **自动匹配政治面貌**：兼容 Excel 与学校系统中的不同字段表述。
- 🧪 **安全测试模式**：正式录入前可以先测试填写效果。
- 🛑 **异常自动停止**：字段定位失败时停止操作，避免误填。
- 📸 **错误截图记录**：方便排查网页结构变化导致的问题。
- 📋 **指定录入范围**：支持从指定成员开始，或限制本次录入人数。
- 🔒 **人工最终确认**：不会自动点击最终的“申请”按钮。

## 🛠️ 环境准备

推荐使用：

- Windows 10 / Windows 11
- Python 3.10+
- Google Chrome
- VS Code（可选）

### 1. 安装依赖

打开 PowerShell 或 VS Code 终端：

```powershell
py -m pip install playwright
```

### 2. 安装浏览器组件

如果使用 Playwright 独立浏览器模式：

```powershell
py -m playwright install chromium --no-shell
```

如果使用 Chrome 远程调试模式，则需要先启动支持调试连接的 Chrome。

## 🚀 快速开始

### 第一步：启动 Chrome

对于使用 Chrome 远程调试连接的脚本版本，在 PowerShell 中执行：

```powershell
& "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="$env:LOCALAPPDATA\ChromeAutomation"
```

启动后，在打开的 Chrome 中：

1. 访问华南理工大学办事大厅。
2. 使用个人账号完成登录。
3. 进入「批量新增社团成员」页面。
4. 选择需要录入成员的社团。

学校办事大厅地址：

https://ehall.scut.edu.cn/fp/view?m=fp#act=fp/formHome

### 第二步：测试自动填写

```powershell
py import_members.py
```

程序将尝试读取第一位成员的信息并填写到新增弹窗中。

**测试模式不会点击弹窗的“确定”按钮。**

请核对学号、姓名、联系电话、政治面貌是否正确。

### 第三步：测试添加一位成员

```powershell
py import_members.py --commit --limit 1
```

程序会尝试添加第一位成员。

请检查该成员是否成功出现在页面的成员列表中。

### 第四步：批量录入全部成员

确认脚本正常运行后：

```powershell
py import_members.py --commit
```

程序将依次填写成员信息并尝试添加至当前申请表。

**注意：程序不会自动点击页面底部的“申请”按钮，最终提交需要人工确认。**

## ⚙️ 进阶用法

从第 10 位成员开始录入：

```powershell
py import_members.py --commit --start 10
```

仅录入 5 位成员：

```powershell
py import_members.py --commit --limit 5
```

从第 10 位开始录入 5 位：

```powershell
py import_members.py --commit --start 10 --limit 5
```

使用 `--start` 前，请确认此前成员已经存在于当前申请表中，避免出现重复或遗漏。

## 🔧 技术实现

本项目使用 Playwright 操作学校办事大厅的网页界面。

主要技术包括：

- **iframe 定位**：自动查找嵌入页面中的“新增”按钮。
- **DOM 元素定位**：识别新增弹窗中的必填输入框。
- **Bootstrap Select 适配**：自动操作政治面貌下拉菜单。
- **字段映射**：兼容不同来源的政治面貌名称。
- **结果检测**：尝试验证成员是否出现在临时列表中。
- **异常处理**：操作失败时停止运行并保存调试信息。
